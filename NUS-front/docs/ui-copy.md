# 师砺平台界面术语表与文案规范（V1.0.1.6）

参照 ScholarOS《界面术语表与文案规范》第 3 节，按师砺平台的业务改写。界面上的文字（页面、组件、提示、确认框、空态、错误、状态）都按这里写；自动检查见第 4 节。数据库里的菜单名、字典标签与后端通知模板不在前端检查范围内，需要时另行修改。

## 2. 保留英文

产品与技术名照原样写：AI、OpenAI、DeepSeek、Ollama、Redis、Druid、SkyWalking、SQL、Java、OAuth 2.0、OpenID、UnionID、API、URL、IP、JSON、Web、H5、App、PDF、Word、Excel、PPT、Office、XLSX、Markdown、HTML、CSS、JavaScript、MCP、Cron（写「Cron 表达式」）。其余界面文字不出现英文单词：Token 写「令牌」，UA 写「浏览器标识」，URI 写「请求地址」，Path 写「路径」。

只在管理端出现的：「ID」只用于排障信息（日志、令牌、三方用户），面向教师和学生的写「学号」「编号」；对象存储配置要与云服务控制台对得上，首次出现写「存储桶（Bucket）」「访问密钥（AccessKey）」这样的中文加英文；Redis 的持久化方式 AOF、RDB 照原样写。

## 3. 文案规范

### 3.1 语气

1. 平实、具体，说清对象、现状和能做什么。
2. 称呼统一用「你」，不用「您」；多数标签可以省略称呼。
3. 不用感叹号，不写「恭喜」「太棒了」「加油」。
4. 不用宣传腔：赋能、助力、一站式、全方位、无缝、轻松、一键、智能化、深度洞察、精准、极致、打造、旅程、解锁、保驾护航、开启……之旅。
5. 不用工程与管理行话：闭环、贯通、收口、落地、抓手、底座、口径、对接（写「接入」或具体动作）。

### 3.2 不写内部引用

6. 界面上不出现字段名、接口名、枚举原值、配置项名、类名与内部编号。
7. 不出现开发占位：「待接入」「待开发」「TODO」「mock」「测试数据」。没上线的功能写「暂未开放」和现在能做什么。

### 3.3 长度

8. 按钮 2～8 字（写明批量范围的可以更长）；导航、表头 2～10 字；状态标签不超过 8 字。
9. 页面常驻说明不超过两句、约 60 字；悬浮提示不超过 80 字；空态与错误正文不超过 100 字；确认框正文不超过 180 字。

### 3.4 按钮与确认

10. 按钮用动词短语：「新建任务」「提交」「打回重做」「导出成绩册」。不用「操作」「处理」「前往」作主按钮。
11. 确认框标题写具体动作和对象（「打回赵一鸣的提交？」）；正文写后果和怎么恢复；主按钮重复动作（「打回」），另一个按钮写「返回」。
12. 提交后不能撤回的，提交前写明「提交后不能撤回」和具体影响。
13. 批量按钮写明范围（「打回所选 3 份」），不写「一键」。
14. 提交中写「正在提交…」并禁止重复提交。

### 3.5 错误、空态、加载

15. 错误按「什么没成功—已知原因—下一步」写：「保存成绩没有成功：网络中断。稍后重试，已填的评语还在。」原因未知就写未知，不猜；不写「请求失败」「操作失败」这类空话。
16. 空态分三种：还没有数据（写怎样会有）、筛选没有结果（给「清除筛选」）、前置条件不满足（写缺什么、怎么满足）。
17. 加载写对象：「正在读取提交记录…」；通用写「加载中…」。
18. 部分失败保留已读到的内容，写明哪部分没读到并给局部重试。

### 3.6 数字与时间

19. 数字用阿拉伯数字；零写 0，未知写「—」。
20. 百分比「83.2%」（% 前不空格）；分数「88 分」；份数「3 份」。
21. 时间写「2026-10-06 19:46」；相对时间（「3 天后截止」）旁边能看到完整时间。

### 3.7 标点与空格

22. 中文句子用全角标点：，。；：？（）。冒号一律「：」（时间、网址里的除外）。
23. 引号一律用「」，引号里再套引号用『』；不用 “” ‘’。引用按钮名、页面名也用「」。
24. 中文与英文、数字之间空一格；数字与单位之间空一格；% 前不空格；中文标点旁不再加空格。
25. 省略号只用「…」，只在加载与截断处用。
26. 「·」分隔并列的元信息（「Web 前端开发实训 · 软件工程 2025 级 1 班」）。
27. 短标签、表头、按钮不加句号；完整句子加句号。

## 4. 自动检查

前端单测（`pnpm test:unit` 里的文案扫描）从页面、组件、布局与工具函数里取出用户看得到的文字，检查：称呼「您」、感叹号、宣传腔与行话、开发占位与内部引用、非标准术语（第 1 节「不用」一列）、中文句子里的半角标点。存量问题登记在基线里，新出现的直接让测试失败；改掉存量问题后同步收紧基线。改本表时同步改扫描规则。
