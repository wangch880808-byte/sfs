# A4 本地口径验收

1. 在一次性 MySQL 容器载入基线 `NUS-doc/3-数据库文件/ry261-test.sql`，应用合并后的 V16（含 A4 片段），再执行 `fixture.sql`。固定 ID 使用 910001 起；请在空测试库执行。
2. 启动指向该容器的本地后端。准备拥有统计与任务记录查询权限的管理员令牌，以及学生二（ID 910002）的本地测试令牌。样本账号的 `password` 为空，不能用于登录；令牌由审核人的本地测试认证工具生成，勿给这些账号设置可用口令。
3. 设置 `A4_BACKEND_URL=http://127.0.0.1:48080`、`A4_ADMIN_TOKEN`、`A4_STUDENT_TOKEN`，运行 `python3 check-metrics.py`。脚本只接受 localhost 地址，也拒绝 HTTP 跳转。

`expected.json` 记录分档、竞赛名次、指派任务数、报告可获证和 AI 草案计数的预期与计算过程。管理员看板可能含基线记录，脚本只断言样本对 AI 批改数的最小贡献。
