# admin-001任务简报

> 历史需求讨论，2026-09-05 归档。以下内容保留早期方案与未完成讨论，不作为当前菜单、权限或实施任务的依据。

1. 构建用户管理，使用user_type字段区分用户(0-教务管理人员｜1-教师｜2-学生)

2. 构建基本菜单树：

   ```shell
   系统
   ├── 教务组织（高校教学组织与人员管理主入口）
   │   ├── 组织架构（学校 / 学院 / 专业）（复用【系统管理 → 部门管理】；部门树只维护“学校 → 学院”，用于角色数据权限按学院隔离）
   │   ├── 班级管理（班级 = 学院 + 专业 + 年级 + 班级名；年级作为字典 gradeYear，不单独做菜单）
   │   ├── 教师管理（复用用户体系；默认 userType=1；扩展教师档案：工号、职称、所属学院）
   │   └── 学生管理（复用用户体系；默认 userType=2；扩展学生档案：学号、班级、入学年份、学籍状态）
   │
   └── 权限与基础（尽量复用框架现有功能）
       ├── 用户管理（系统账号与行政人员管理；教师/学生一般不从这里维护）
       ├── 角色管理（维护角色：学校教务、学院教务、教师、学生；并配置数据范围）
       ├── 岗位/职称管理（复用岗位管理；维护教师职称/职务，如讲师、副教授、辅导员等）
       ├── 菜单管理（系统菜单与按钮权限配置；建议仅超级管理员可见）
       └── 字典管理（维护枚举值：学籍状态、教师类型、学生状态等）
   ```
