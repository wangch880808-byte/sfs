## 格式

新记录复制下面的结构，文件名 `ADR-00N-简短标题.md`，并加到上表：

```markdown
# ADR-00N 标题

- 状态：生效 / 已被 ADR-00M 取代
- 相关版本：
- 日期：

## 背景
## 决定
## 理由
## 后果
## 出处
```

每条都要能在版本说明、历史计划或提交日志里找到依据。
