# ADR-003 取消草稿，复制任务直接发布

- 状态：生效
- 相关版本：V1.0.1.7（复制为草稿）、V1.0.1.10（取消草稿）
- 日期：2026-10-13

## 背景

- V1.0.1.7 加了“复制任务”：在任务列表勾选任务，“复制到”其他学期或班级，生成**草稿**（状态 0），截止时间清空，老师发布前再填。为此 `edu_homework.deadline` 改为可空，并加了参数 `edu.homework.copy.max-drafts`。
- 批量复制没法给每个任务改内容；生成的草稿还要逐个打开、填截止时间、发布，步骤多。
- 同一时期还发现，课程详情“新建任务”的班级下拉框混用了班课编号和班级编号，任务会建到别的班。复制和新建本该共用一份表单和一套校验。

## 决定

- 不再新建草稿。新建、编辑接口都不接受草稿状态。
- “复制”改为打开预填好原任务全部内容的“复制任务”表单，老师选班级（可多选，每班一个任务）和截止时间，确认后**直接发布**，与新建任务一样分配学生、发通知。
- 去掉列表上的“批量复制”；旧的复制接口下线（`/edu/homework/copy/targets` 保留，给表单提供可选班课）。
- 新建接口可选接收 `sourceHomeworkId`（记录来源）和 `classCourseId`（核对班课与课程、班级、学期一致）。
- 已封存的往期任务也能复制，用于把上学期的任务搬到新学期。
- 旧草稿：列表显示为“待发布”；老师编辑保存时后端自动发布，截止时间必填。

## 理由

- 复制和新建走同一个表单，老师一步完成，并且可以按班级调整内容。
- 少一个“发布前的中间状态”，学生端、统计都不用再处理草稿。
- 复用新建的校验，顺带堵住多班级建错班的问题。

## 后果

- 任务状态 0 只剩历史数据，字典文字改为“待发布”（V21）。分析类统计不计状态 0。
- 参数 `edu.homework.copy.max-drafts` 不再使用，保留无影响。
- 旧复制接口下线，接口权限快照和权限矩阵已同步。
- 前端 `HomeworkForm.vue` 里，课程固定的场景（课程详情新建、复制）按场景判断，不做课程、指标级联，避免异步回调把班级选项换掉（见 `NUS-front/AGENTS.md` 第 1、2 条）。
