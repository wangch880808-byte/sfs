# 师砺平台 V1.0.1.4 增量更新说明

适用范围：已安装 V1.0.1.3（Flyway 版本 14）的离线环境。升级后 Flyway 版本为 15。

## 一、重要：安全修复

1. **权限校验恢复生效**。此前框架中的“跳过权限校验”判断对所有已登录用户成立，导致学生等任意登录用户可以调用管理接口。本版已修复，所有接口按角色授权严格校验。
2. **关闭匿名入口**：
   - 删除 `/app-api` 下的全部接口，包括匿名文件上传和匿名字典读取；
   - 删除自助注册、短信验证码登录、短信重置密码、短信回调、OAuth2 开放端点、公告 WebSocket 推送。
3. **越权修复**：
   - 删除批量重置密码接口；
   - 成绩册导入导出改为按任务所属课程校验；
   - 题库删除校验归属；
   - 课程封面只能使用本次上传或默认封面；
   - 课程资源只能登记本人上传到该课程目录的平台文件，堵住服务端请求伪造（SSRF）；
   - 学生下载课程资源改为流式输出。
4. **下载安全**：SVG 等可执行脚本的文件一律按附件下载。
5. **交付物**：后端 jar 不再包含本地和开发环境配置。

## 二、功能修复

1. **学生端提交**：Web 学生端带附件的作业恢复可提交，改用作业专用上传接口。
2. **打回重做**：打回时可以设置“重做截止时间”，任务截止后打回也能按期重交；已打回的记录可以调整重做期限；批量打回恢复可用。
3. **AI 初评**：AI 初评使用任务实际关联的技能指标名称。
4. **学生“我的课程”**：不再弹出“没有该操作权限”。
5. **仅有教师角色的账号**：可以正常打开实训任务列表与详情；可以修改、删除本人创建的课程；在班级详情里给本班学生留言会校验归属。
6. **助教**：教学统计与 AI 分析的课程选项包含本人担任助教的课程。

## 三、数据库变更（V15，自动执行，可重复执行）

- **结构**：新增 `edu_homework_record.redo_deadline`；新增 3 个查询索引。
- **配置**：
  - 关闭自助注册开关；
  - 批量导入非学生账号的默认初始密码如果仍是上游默认值，将被清空，导入时需要在向导里填写（学生花名册仍以学号为初始密码）。
- **菜单**：
  - 停用短信管理、邮箱管理、OAuth2 应用管理、AI 工具管理（仅隐藏，可在菜单管理中恢复）；
  - 删除已停用的表单构建、API 接口、数据源配置，以及页面已不存在的校园资讯管理端和孤立的统计分析菜单。
- **字典**：
  - 补回“菜单类型”“数据权限范围”“用户类型”三个字典；
  - 停用后端不支持的 AI 平台和社交登录类型（仍在使用的保留）；
  - 隐藏不可用的钉钉登录入口。
- **角色**：
  - “教师”和“学校教务管理员”的数据范围设为“全部数据权限”，与此前的实际行为一致；
  - “学校教务管理员”补授用户查询、班级查询、管理员看板三项只读权限。
- **定时任务**：新增 API 访问日志、API 错误日志（保留 180 天）和定时任务日志（保留 30 天）的清理任务。
- **AI 工具**：停用已删除的三个演示工具。

## 四、升级步骤

1. 将升级包复制到服务器，执行 `sha256sum -c` 校验压缩包。
2. 解压后在包目录执行：`sudo ./upgrade.sh "$PWD"`。
   脚本会自动：
   - 备份 `.env` 与数据库；
   - 构建新镜像；
   - 执行 V15；
   - 清理菜单与权限缓存；
   - 依次启动后端和前端并检查健康状态。
3. 升级后执行 `nusctl status`、`nusctl doctor`，并用各类角色账号登录检查常用页面。

## 五、回滚

1. **恢复数据库**：`nusctl restore <升级时生成的备份文件>`（V15 无法自动回退）。
2. **恢复旧镜像标签**：用 `/srv/nus/config/.env.before-V1.0.1.4-<时间>` 恢复 `.env`，把镜像标签改回 V1.0.1.3。
3. **重新启动服务**：将 `/srv/nus/current` 指回 V1.0.1.3 的发布目录后，执行 `docker compose up -d`。

## 六、升级后需要学校确认的事项

1. **角色授权**：权限校验恢复后，各角色只能使用被授予的功能。“学院教务管理员”角色目前没有任何授权；如果有在用账号，请在“角色管理”中配置。
2. **学生数据外发开关**：`NUS_AI_EXTERNAL_STUDENT_DATA_ENABLED` 维持部署默认开启，即允许把学生作答内容发送给已配置的 AI 模型。如需关闭，请修改 `.env` 后重启后端。
3. **nginx 配置**：删除 `/app-api`、`/infra/ws` 转发的改动已在源码中完成，但要随下一个完整包才生效。本增量包通过删除后端接口实现同等封堵。

## 七、已知问题（计划在 1.0.1.5 处理）

1. 管理员看板接口目前只校验“统计查询”权限，教师也能读取全校汇总数字（不含个人信息）。
2. 深色主题下弹窗遮罩偏淡，弹窗四周的页面文字仍清晰可见（vben 全局样式）。
3. 权限码与菜单的对应关系仍有历史遗留：课程与评价指标共用权限码，教务管理员的授权需要按学校实际分工进一步梳理。
