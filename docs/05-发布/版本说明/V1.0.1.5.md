# 师砺平台 V1.0.1.5 增量更新说明

适用范围：已安装 V1.0.1.4（Flyway 版本 15）的离线环境。升级后 Flyway 版本为 16。

## 一、升级前必读

1. **学生必须修改初始密码**：升级后，全体学生账号（含存量账号）在 Web 端用密码登录后，必须先修改初始密码才能使用其它功能；改密成功后，该账号的其它登录会话失效。管理员重置学生密码后同样要求改密。教师、管理员账号不受影响，微信小程序登录不受影响。建议升级前通知学生。
2. **“删除”改为“归档”**：
   - 班级、课程、实训任务、班课绑定的“删除”改为“归档”：数据保留，学生不可见，不计入统计；在列表中打开“显示已归档”即可恢复。
   - 教务侧“教师管理”“学生管理”的删除改为“停用账号”，可以恢复。“系统管理 → 用户管理”的删除保持原样。
3. **统计数字会变化**：口径统一后，部分统计结果与旧版本不同，详见“三、统计口径调整”。
4. **等级解锁开始强制执行**：学生需要上一等级任务的达标率达到 80%（可配置），才能开始下一等级的新任务。上一等级没有任务时不受限制；已经提交过的任务不受影响，仍可查看和重交。

## 二、新增与改进

1. **评分轨迹**：
   - 记录每份作业的提交、重交、批改、复评、打回、调整重做期限等全过程；
   - 教师批改页和学生反馈页都可以查看；
   - 打回时保留原成绩，学生重交并被重新批改后才覆盖；
   - 批改前校验记录状态：只能批改“待批改”“已重交”的记录，或对“已批改”的记录复评；已发布或已截止的任务不能改回草稿。
2. **公共课自动覆盖所有班级和教师**：
   - 已审批且状态正常的公共课，自动关联所有正常班级（当前学期），包括新学期新建的班级；
   - 恢复班级或课程、切换学期时立即同步，另有每日 0:15 的兜底任务；
   - 管理员手动归档的公共课关联不会被自动恢复；
   - 所有教师都可以查看公共课，并给已关联的班级布置任务；任务的批改权仍只属于布置者。
3. **留言互动**：
   - 开放教师“留言互动”菜单，显示学生真实姓名和未读条数；
   - 学生新增“我的留言”，课程详情页新增“联系老师”入口；
   - 会话关闭后双方都不能再发送，只有教师可以重新打开；
   - 只有课程教师、课程团队成员和该班课的助教可以查看和回复。
4. **钉钉登录按配置显示**：
   - 在“系统管理 → 社交客户端”中配置钉钉（用户类型选管理后台，填写 AppKey、AppSecret 并启用）后，登录页自动出现钉钉入口；未配置或停用时不显示。
   - 社交登录失败时显示真实原因，只有“账号未绑定”时才出现绑定表单。
5. **AI 评阅可靠性**：
   - 单次调用设硬超时，默认 180 秒；
   - 只对网络错误、服务端错误和限流重试，最多 2 次；
   - 服务重启后自动恢复排队中的初评和批量评阅，长时间没有进展的任务标记为失败，并显示原因；
   - 学生作答超过 8000 字时截断，并与提示词隔离，防止作答内容中夹带指令；
   - 批改页的 AI 进度轮询最长 10 分钟，超时后可以手动刷新。
6. **教师反馈闭环**：
   - 教师对 AI 评分的“加严 / 正常 / 放宽”反馈，以及教师终评与 AI 初评的分差，会按当前任务汇总；样本不足时按同一课程汇总。
   - 汇总结果形成校准提示，自动用于之后的 AI 初评。样本少于 5 条时不校准。
   - 批改页显示当前的校准状态。
7. **学生能力报告**：按证书阈值显示“可获证”判定。
8. **AI 对话按菜单授权**：AI 对话的相关接口改为按“AI 大模型 → AI 对话”菜单上的权限标识 `ai:chat:use` 校验。被授予该菜单的角色照常使用；未授予的角色（如学生）不能再直接调用接口。今后谁能使用，在“角色管理”中勾选该菜单即可。

## 三、统计口径调整

| 指标 | 旧口径 | 新口径 |
|---|---|---|
| 应交人数 | 按当前班级人数推算 | 按任务发布时的指派名单；学生入班后补发该班未截止的任务，出班时移除尚未提交的未截止任务 |
| 及格线 | 多处写死 60 分 | 一律取任务自身的及格线；新建任务的默认及格线读取参数 `edu.pass.score` |
| 成绩分档 | 固定分数段，边界可能重叠 | 按满分比例划分：不合格、合格、良好（默认 75% 起）、优秀（默认 85% 起），四档互不重叠 |
| 排名 | 同分按先后顺序排名 | 同分并列（如 1、1、3） |
| 学年 | 按 8 月 1 日推算 | 按“学期管理”中的学期名称 |
| 能力综合分 | 未按指标权重计算 | 按一级指标权重加权；权重缺失时等权平均 |
| 管理员看板“AI 批改数” | 依赖一个从未写入的字段，结果始终不准确 | 保留该指标，改为“已批改且有成功 AI 初评草案”的份数 |

分档比例和解锁比例可以在“参数配置”中调整：`edu.score.good-ratio`、`edu.score.excellent-ratio`、`edu.course.unlock-ratio`。

## 四、下线的功能

- 旧的“统计分析”页、“学生统计列表”，以及只供它们使用的课程、班级、院系、学生明细报表导出；
- 教务侧独立的“AI 对话”“AI 分析”页（“AI 大模型 → AI 对话”保留，“教学问题研判”中的 AI 分析保留）；
- “班课关联”独立页面（在课程详情中绑定班级）；
- 作业排名接口和学生报告中的排名趋势；
- 后端作业草稿接口。学生端本地草稿保留，改为按账号隔离，退出登录时清除；
- 登录页功能开关字典（只服务于不可用的演示按钮）；
- 上游脚手架功能：短信、邮件、WebSocket、地区与 IP、数据源配置、AI 绘画等。文件存储的本地、数据库、S3、FTP、SFTP 均保留。

## 五、问题修复

1. 在“部门管理”中新建组织且不填组织编码时报错（此前版本即存在）。
2. 学生端本地草稿在公共电脑上可能被其他同学看到。

## 六、数据库变更（V16，自动执行，可重复执行）

- **结构**：
  - `system_users` 新增“需修改密码”标记；
  - 新增评分轨迹表 `edu_homework_record_history`；
  - `edu_class_course` 新增归档状态，`edu_homework` 新增归档前状态；
  - `edu_message` 新增已读状态、阅读时间和会话索引；
  - `ai_edu_review_task` 新增发起教师、认领令牌、失败原因。
- **数据**：
  - 存量学生标记为需修改密码（只在首次升级时执行）；
  - 为在线公共课回填当前学期的班级关联（需要已设置当前学期）；
  - 历史留言回填已读状态：已有教师回复的学生留言视为已读，仍在等待回复的保持未读。
- **菜单与字典**：
  - 下线短信、邮件、地区等脚手架菜单与字典；
  - 下线旧统计页、学生统计列表、教务侧 AI 独立页、班课关联页菜单，班课绑定按钮移到“实训课程管理”下；
  - 开放教师“留言互动”，新增学生“我的留言”；
  - 删除登录页功能开关字典。
- **参数**：新增成绩良好比例（0.75）、优秀比例（0.85）、等级解锁比例（0.8）；移除未使用的“当前学年”参数。
- **定时任务**：新增“公共课班级同步”（每日 0:15）。
- **AI 对话**：给“AI 对话”页面菜单设置权限标识 `ai:chat:use`（菜单被学校改动过时不修改）。

## 七、升级步骤

1. 将升级包复制到服务器，执行 `sha256sum -c` 校验压缩包。
2. 解压后在包目录执行：`sudo ./upgrade.sh "$PWD"`。
   脚本会自动：
   - 备份 `.env` 与数据库；
   - 构建新镜像；
   - 执行 V16；
   - 清理菜单与权限缓存；
   - 依次启动后端和前端并检查健康状态。
3. 升级后执行 `nusctl status`、`nusctl doctor`，并用各类角色账号登录，检查常用页面。

## 八、回滚

1. **恢复数据库**：`nusctl restore <升级时生成的备份文件>`（V16 无法自动回退）。
2. **恢复旧镜像标签**：用 `/srv/nus/config/.env.before-V1.0.1.5-<时间>` 恢复 `.env`，把镜像标签改回 V1.0.1.4。
3. **重新启动服务**：将 `/srv/nus/current` 指回 V1.0.1.4 的发布目录后，执行 `docker compose up -d`。

## 九、升级后需要学校确认的事项

1. **提前通知学生**：首次登录需要修改初始密码。
2. **当前学期**：确认“学期管理”中已设置当前学期。公共课自动关联依赖它；未设置时不回填，设置后会自动同步。
3. **钉钉登录**：如需启用，在社交客户端中完成配置。
4. **分档与解锁比例**：如需调整，在“参数配置”中修改上述参数。
5. **AI 对话的使用范围**：确认哪些角色需要使用“AI 大模型 → AI 对话”，在“角色管理”中为其勾选该菜单（未勾选的角色升级后不能再调用 AI 对话接口）。

## 十、已知问题

1. **学生角色的数据范围为“全部”**：用户和部门的精简列表接口对学生可见，只含昵称和所属部门，不含联系方式。
   - 已在本地实测：如果直接在“角色管理”中把学生的数据范围改为“仅本人”，学生端课程列表、课程详情、留言中的授课教师姓名，以及学生本人的院系、专业名称会显示为空。
   - 因此本版暂不调整。计划在 1.0.1.6 中先让这几处查询不受数据范围影响，之后学校即可按需把学生配置为“仅本人”。
2. **1.0.1.4 遗留问题**：“教师可读取管理员看板汇总”“权限码共用”仍保持原状（本版按约定沿用现有权限模型）；深色主题弹窗遮罩偏淡的问题也未处理。
