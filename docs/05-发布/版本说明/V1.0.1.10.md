# 师砺平台 V1.0.1.10 增量更新说明

**适用范围**

- 已安装 V1.0.1.9（Flyway 版本 20）的离线环境，升级后 Flyway 版本为 21。
- 从 V1.0.1.8 或 V1.0.1.8.1（Flyway 19）升级时，会先执行 V1.0.1.9 的迁移 V20，请同时阅读《V1.0.1.9 增量更新说明》。

本版主要内容：

- 公共课由教师**认领班级**，各管各的班；
- 修正从课程详情一次选多个班级新建任务时，任务可能建到别的班级的问题；
- “复制任务”改为弹出预填好的表单，直接发布；
- “归档”改称**封存**，封存的数据仍计入统计；新增真正的**删除**；
- 课程详情的班级、任务加“负责人”列和筛选；
- 任务内容里的大图片按屏幕宽度缩小，点击可以放大查看。

## 一、升级前必读

1. **请老师核对用多班级新建的任务**：旧版本从课程详情一次选择多个班级新建任务时，任务有可能建到了**别的班级**（见第三节）。数据库里无法区分哪些建错了，请老师在课程详情的任务列表里核对：任务所在班级不对的，可以用新的“删除”去掉后重新布置。
2. **统计数字会变化**：封存的班级、课程和任务现在计入合格率、成绩趋势、课程分析和学生排名（见第五节），往期数据会重新出现在这些分析里。看板上的总数仍只算在用的。
3. **旧版的“草稿”**：本版不再有草稿。旧版复制产生的草稿在列表里显示为“待发布”，老师打开编辑、填好截止时间并保存后即发布给学生。
4. **数据库迁移 V21**：
   - 给班课关联加认领字段，并按历史任务回填认领人；
   - 把任务状态的“草稿”“已归档”两个文字改为“待发布”“已封存”。
   - 可以重复执行，数据量在几万条以内只需几秒。
5. **升级后请重新登录**，以加载新的菜单和权限。

## 二、公共课认领班级

公共课面向全校所有班级。之前任何老师都能给任何班布置任务，可能出现两位老师给同一个班重复上课。本版改为由教师**认领**班级：

- **认领**：在公共课的课程详情里点“认领班级”。已被别人认领的班级排在列表下方、变灰不可选，并标明认领老师。同一班级、同一学期只能由一位老师认领；两人同时认领同一班级时，只有一人成功。
- **只看自己的班**：教师打开公共课，只看到自己认领的班级和自己布置的任务。布置任务、学生名单、留言、成绩和统计都只限自己认领的班级。
- **课程负责人**：可以只读查看全部班级和任务，每个班级都标明认领人；自己认领的班级照常管理。
- **课程团队成员**：和普通教师一样，只看自己认领的班级。
- **放弃认领**：教师可以随时放弃。已经布置的任务仍归原布置者，原布置者照常查看、批改和修改。
- **清除认领**：管理员和公共课审批人可以清除任一班级的认领，例如教师离职时。
- **每学期分别认领**：新学期开始时由教师重新认领。
- **历史数据**：升级时按已布置的任务回填认领人：本学期这个班这门课里只有一位老师布置过任务的，认领人就是这位老师；其余班级留空，由老师自己认领。
- **权限收紧**：公共课的成绩册导入、花名册导入、留言回复，只允许布置者、认领人、班课助教和管理员操作。课程负责人和审批人只能查看。

专属课程的规则不变。

## 三、修正：多选班级新建任务建错班

**现象**：在课程详情里点“新建任务”，选择多个班级后提交，有的任务建到了没有选的班级。

**原因**：新建弹窗打开后，班级下拉框的选项在后台被换成了另一种编号，提交时两种编号混在一起，编号碰巧重合时就建到了别的班。

**修正**：

- 班级下拉框统一使用同一种编号，不再混用；
- 后端再核对一次所选班级与课程、学期是否一致，不一致直接拒绝；
- 打开新建弹窗时，“指定班级”“二级指标”不再一打开就标红。

## 四、复制任务

- 在任务列表或课程详情的任务行上点“复制”，弹出“复制任务”表单。原任务的名称、类型、等级、指标、批改方式、提交方式、分值、及格线、任务内容和 AI 评分标准都已填好。
- 老师只需选择班级（可多选，每个班生成一个任务）和截止时间（有 1–7 天的快捷按钮），确认后**直接发布**，学生马上能看到。
- **已封存的往期任务也能复制**，方便把上学期的任务搬到新学期。
- 列表上的“批量复制”去掉了。

## 五、封存与删除

**封存**（原“归档”，全站改称）：

- 封存后只读：不能再修改、批改，学生的待办里不再出现，可以随时恢复。
- **统计照常计入**：合格率、成绩趋势、课程分析、学生排名、AI 班级分析，都计入已封存的任务、班级、课程和班课。
- 看板上的总数（学生、教师、课程、任务）和待办类指标（待批改、本周提交、最近任务）只算在用的。
- 班级、课程、班课、学期收尾的“归档”都改称“封存”，含义相同。

**删除**（新增，只针对实训任务）：

- 任务列表和课程详情的任务行上都可以删除，任务列表还支持批量删除。
- 只有布置者本人和管理员可以删除。
- 删除前会提示影响范围：有学生提交时，提示提交和成绩将从所有统计中移除，且不能恢复。
- 删除后，任务和它的学生分配、提交、成绩、AI 批改记录、延期和提醒都一并删除，不再计入任何统计，学生端也不再显示。

**课程详情的任务页**：

- 新增“显示已封存”开关，默认不显示已封存的任务；
- 已封存的任务可以恢复、复制、删除。

## 六、课程详情：负责人列和筛选

- **班级页**新增“负责人”列：
  - 公共课：显示认领人，没人认领的显示“未认领”；
  - 专属课程：显示添加这个班的老师，由管理员或系统添加的显示课程负责人。
- **任务页**新增“负责人”列，显示任务布置者。
- 两个页面都可以按负责人筛选。公共课的班级页还可以筛出“未认领”的班级。

## 七、任务内容里的图片

- 任务内容里的图片、视频按显示区域的宽度**等比缩小**，在分辨率不高的屏幕上也能看全，不再变形。
- 鼠标停在图片上显示放大镜，**点击打开大图预览**，可以放大、缩小、旋转，多张图片可以左右切换。
- 很宽的表格、代码块可以横向滚动，不再撑破页面。
- 涉及的页面：新建任务的预览、任务详情、批改页、学生提交页。批改页之前把任务内容当纯文本显示，会露出 HTML 标签，现在正常显示。

## 八、其他修正

- **在“用户管理”里新建学生或修改学生的班级时，补发班里未截止的任务**：之前只有在班级里添加学生、导入学生时才补发，用户管理里加进班的学生看不到、也提交不了已布置的任务；移出班级时也同步撤下这些任务。
- 任务列表里只选“已封存”筛选、但没打开“显示已封存”时，结果总是空的；现在会自动打开开关。
- 班课详情的成绩分析不再计入旧版草稿。

## 九、数据库变更（V21）

可以重复执行：

- `edu_class_course` 新增 `claim_teacher_id`（认领教师）、`claim_time`（认领时间）两列和两个索引，并按历史任务回填认领人（规则见第二节）；
- 任务状态字典：“草稿”改为“待发布”，“已归档”改为“已封存”。管理员改过的字典文字保持不变；
- 全量安装包的数据库基线升到 21。

## 十、升级步骤

在服务器上解压增量包后执行：

```bash
sudo ./upgrade.sh
```

- 升级完成后执行 `sudo nusctl status`，确认各服务健康。
- 如需回退：执行 `sudo nusctl rollback previous`，数据库会恢复到升级前的备份。**注意：回退会丢失升级后产生的数据**，正式环境请先联系维护人员。

## 十一、已知限制

- 参数表里旧复制功能的配置项 `edu.homework.copy.max-drafts` 已不再使用，保留无影响。
- 已经发出的站内通知不会因为删除任务而撤回；点开已删除任务的通知会提示任务不存在。
