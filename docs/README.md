## 写文档的约定

- **一个主题只有一份现行文档**，其他地方只放链接，不复制内容。
- **文档开头写三行**：面向谁、适用版本、最后核对日期。
- **改了代码就同步文档**：
  - 用户能看到的变化写进 CHANGELOG 和用户操作手册；
  - 运维方式变了，更新运维手册。
- **历史文档不改**：内容过时也不改，在现行文档里写清楚新的做法。
