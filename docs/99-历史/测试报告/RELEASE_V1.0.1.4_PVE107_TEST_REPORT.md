## 本版内容

- **安全**：
  - 修复“已登录即跳过全部权限校验”；
  - 删除 `/app-api`、自助注册、短信登录与重置、OAuth2 开放端点、批量重置密码、公告推送；
  - 成绩册、题库、课程封面、课程资源（SSRF）越权修复；
  - SVG 改为按附件下载；
  - jar 不再包含 local/dev 配置。
- **功能**：
  - Web 学生端附件提交；
  - 打回重做期限及其调整；
  - 批量打回；
  - AI 初评使用真实指标名；
  - 学生课程页不再报权限错误；
  - 仅教师账号的任务页；
  - 教师维护本人课程与班级留言；
  - 助教课程选项。
- **数据库（V15）**：
  - 新增重做截止列与 3 个索引；
  - 关闭注册开关、清空上游默认初始密码；
  - 停用或删除脚手架菜单，补回字典，停用不支持的 AI 平台与社交类型；
  - 教师与学校教务管理员数据范围设为“全部”，学校教务管理员补授 3 项只读权限；
  - 新增日志清理任务，停用演示 AI 工具。
- **发布工程**：
  - 备份与恢复脚本加入 pipefail 和完整性校验；
  - 升级前备份 `.env`，拒绝与当前相同的镜像标签，升级时清理权限缓存；
  - 增量打包自动生成元数据、压缩包与校验和。
- 详见包内 `更新说明.md`（副本：`docs/RELEASE_NOTES_V1.0.1.4.md`）。
