## V1.0.1.8.1 补丁包（2026-10-10）

- **原因**：学校服务器已经装过早期的 V1.0.1.8 包，升级脚本拒绝同一版本号重复安装。如果先回滚再升级，数据库会恢复到第一次升级前的备份，之后的数据会丢失。
- **做法**：用同一份代码以新版本号 V1.0.1.8.1 打包。已装 V1.0.1.8 的服务器直接执行 `upgrade.sh`，不需要回滚；本包没有数据库变更。
- **升级包**：
  - SHA256：`ed4c70321be51d2be13d2e8bc016e65f11f27b22601556a0938b22923ccde107`；
  - 构建来源：父仓库 `78da70d`（只多了更新说明）、NUS-front `dcd88c4`、NUS-backend `bfd6e7c`。
- **107 验证**：
  - 从 V1.0.1.8 直接升级到 V1.0.1.8.1，没有回滚。升级日志为 `/srv/nus/logs/upgrade/20261010T104946Z-V1.0.1.8.1.log`；
  - 结果：成功，Flyway 仍为 19，前后端 healthy；
  - 健康检查、首页返回 200，受保护接口返回 401；前端包含新文案和流式接口的 nginx 配置。
