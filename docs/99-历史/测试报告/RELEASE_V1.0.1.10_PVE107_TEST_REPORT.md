### 浏览器实测

在本地环境用测试教师账号实测：

- **撞号场景**：造了一个班级，它的编号恰好等于同课另一班级的班课关系编号。从课程详情新建任务时同时选这个班和另一个班，两个任务都建到了所选班级，请求里带了正确的班课编号；打开弹窗时不再标红。
- **复制**：已封存的往期任务可以复制，表单预填原任务内容，截止时间为空；选“7 天”后提交，新任务为已发布，并已分配给学生。
- **删除**：确认框说明影响范围，按钮为红色；删除后任务和学生分配都已移除，列表刷新。
- **负责人列**：班级页、任务页的负责人列和筛选正常；“显示已封存”开关正常。
- **图片缩放**：在 1366×768 窗口下，3200×2000 的大图按原比例缩为 680×425，宽表格横向滚动；点击图片打开预览，可以放大、缩小、旋转。

### 性能对比

同一份造数（6000 名学生、2400 个任务、8.4 万条提交、18 万条站内信），先后用 V1.0.1.9 和 V1.0.1.10 测同样 65 个接口：

- SQL 条数基本不变，耗时在同一范围内波动，没有发现性能退化；
- 返回内容的差异都在预期内：
  - 课程详情和班课列表多了负责人、认领字段，任务页包含已封存的任务；
  - 合格率、成绩趋势、课程分析和统计班级选项计入已封存的任务和班级。

## 备注

- 学校服务器目前为 V1.0.1.8.1，可以直接升级到 V1.0.1.10，升级时会依次执行 V20、V21。
