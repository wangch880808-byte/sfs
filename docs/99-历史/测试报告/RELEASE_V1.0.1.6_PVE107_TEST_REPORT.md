## 本版中发现并已修复的问题

1. 教师打开“留言互动”时课程下拉为空：教师缺“查询班课”只读权限，由 V17 按“拥有留言互动的角色”补齐。
2. 班级课程列表中课程名显示成“课程1”：接口未填课程名，已改为批量读取班级名与课程名。
3. 学校教务管理员看不到“管理员看板”：角色有页面授权但缺上级目录，由 V17 补齐目录。
4. 迁移改了通知模板，但升级时只清理菜单与权限缓存，新文字要等一小时：升级脚本一并清理通知模板缓存。
5. 模型停用提示把占位符原样显示为“({})”；错误日志处理确认总写“已处理”；课程资源上传对话框整宽显示；AI 对话回复失败后“思考中”占位不消失。
6. 深色主题下弹窗遮罩偏淡（1.0.1.4 遗留）；两个汉字的按钮被自动插入空格；浅色下警告与成功提示底色发灰。
