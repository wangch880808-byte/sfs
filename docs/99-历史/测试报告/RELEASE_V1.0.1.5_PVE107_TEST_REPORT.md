## 联调中发现并已修复的问题

1. **后端无法启动**：脚手架清理删除了分布式锁配置类，但自动装配清单中还留着登记。已移除登记，并新增清单校验测试。
2. **新建院系报错**：不填组织编码时，插入违反 `dept_code` 的非空约束。这个问题在之前的版本就存在，已改为先写入临时编码、再生成稳定编码。
3. **学生留言菜单 ID 冲突**：V16 原计划使用的菜单 ID 5126 在基线中已被“数据导入”占用，导致学生拿不到留言权限。已改为按权限标识定位，ID 由自增分配。
4. **基线 16 漏了一条授权**：缺少教师“教务组织”目录授权。已补齐，基线与“基线 15 + V16”一致。
5. **留言升级后未读数激增**：新增已读字段后，历史留言会全部变成未读。已增加一次性回填：已被教师回复的学生留言视为已读。
6. **AI 对话接口只校验登录**：已改为按“AI 对话”菜单上的权限标识 `ai:chat:use` 授权，可在角色管理中配置谁能使用。
