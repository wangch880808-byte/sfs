- 检查保留项：模型连通性与文件存储测试是真实管理功能；教学数据导入模板中的“示例数据”用于说明填写方式；自动化测试及其建表/清理 SQL 保留。
- 待继续核实：旧教学 sprint SQL、回滚 SQL、资源目录建表脚本与现行基线/迁移的覆盖关系；WebSocket 演示页面及其他旧页面的实际部署菜单引用。历史数据库备份不能因含 demo 就判断整个文件无用途，本轮未删除。

验证入口：`python3 deploy/database/tests/check-demo-cleanup.py`，使用无网络、无宿主端口、临时存储的独立 MySQL 容器；验证新基线、22 条原始菜单迁移、授权清理、重复执行和自定义子菜单保护。此命令不连接现有数据库。

## 目标与范围

统一应用展示名称为“师砺平台”，消除用户可见的脚手架品牌、演示内容和误导性链接，同时保留开源归属和业务兼容性。本计划承接 `SCAFFOLD_BRANDING_AUDIT_20260923.md`，当前仅编制计划，不额外执行代码清理、数据库修改或部署。

不以关键词零命中作为验收标准。依赖包名、许可证、来源链接及兼容判断中的关键词可以保留，并注明原因。历史噪音清单只作线索，其中路径、部署版本和数据库状态应重新核对。

1. 明确核查的数据库和环境，不能根据数据量猜测或切换连接。

3. 区分初始化样例、现行业务配置和用户历史内容。仅为确认需要调整的初始化样例及配置编写定向迁移，按主键与旧值共同约束，重复执行不得重复修改。
4. 保留聊天记录、审计日志和用户编写的内容，不进行全库字符串替换。历史 SQL 快照保留原貌，修正现行初始化入口时单独记录变更。

验收：先在明确的测试数据库验证影响行数及重复执行结果；既有菜单权限、登录和 AI 角色选择正常。是否执行线上迁移在实际实施时依据明确的环境和变更范围决定。
