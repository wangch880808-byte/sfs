# NUS 用户操作手册

本文档只面向系统使用人员，帮助教师和学生按照当前系统已经实现的业务流程完成日常操作。

## 一、使用前先了解

当前系统已经形成两条清晰的使用主线：

- 教师主线：创建课程 -> 绑定班级 -> 上传资源 -> 发布实训任务 -> 批改与复盘
- 学生主线：查看提醒 -> 进入课程 -> 完成任务 -> 查看反馈 -> 查看能力报告

如果你是第一次使用，建议优先按照上面的顺序操作，会更顺手。

## 二、教师使用手册

### 1. 教师日常操作顺序

建议教师按下面的顺序开展日常工作：

1. 先查看工作台，了解课程数、待批改数和最近任务。
2. 进入课程列表，建立课程或维护已有课程。
3. 在课程详情里先绑定班级，再补充课程资源。
4. 在课程下发布实训任务。
5. 进入批改页面完成评分、评语、打回重做或 AI 辅助批改。
6. 最后查看统计结果，必要时与学生留言沟通。

### 2. 工作台怎么用

教师登录后，建议先看工作台。

在这里可以快速看到：

- 我的课程数
- 待批改数
- 未读留言数
- 本周新提交数
- 最近创建或更新的实训任务

如果你当天要处理批改，直接从工作台进入“去批改”即可。

### 3. 课程管理怎么做

课程是教师端最核心的入口。课程建好后，后面的班级、资源、任务和批改都会围绕课程展开。

你可以在课程列表里完成这些操作：

- 查看公共课程
- 查看我创建的课程
- 查看我参与的课程
- 搜索课程
- 新建课程
- 编辑课程
- 停用课程
- 删除课程

建议做法：

1. 先建立课程名称和课程简介。
2. 确认课程对应的培养方向或技能方向。
3. 进入课程详情继续补充班级、资源和任务。

### 4. 课程详情怎么维护

进入课程详情后，一般会用到三个区域：班级、实训任务、资源。

#### 4.1 班级

班级页主要用于把这门课程和实际授课班级关联起来。

你可以做的事：

- 按班级名称筛选
- 按学期筛选
- 按状态筛选
- 新增班级
- 查看某个班级的参与详情

推荐操作：

1. 先点“新增班级”。
2. 选择本课程本学期要参与学习的班级。
3. 添加完成后，再去发布任务。

这样做的好处是：任务发布时可以直接面向已绑定班级，不用反复补配。

#### 4.2 实训任务

任务页用于集中发布和管理这门课程下的所有任务。

你可以做的事：

- 新增任务
- AI新建任务
- 编辑任务
- 查看任务详情
- 进入批改
- 查看批改情况
- 删除任务

推荐操作：

1. 先确认课程下已经有班级。
2. 点击“新增任务”录入任务名称、要求、截止时间、适用班级等内容。
3. 如果想更快生成任务，可以使用“AI新建任务”。
4. 任务发布后，持续关注提交进度和批改进度。

#### 4.3 资源

资源页适合上传课程材料，方便学生在学习前或做任务时查看。

适合放在这里的内容包括：

- 课件
- 示例材料
- 任务参考资料
- 操作说明
- 其他学习附件

建议在发布任务前，先把学生完成任务必须参考的资料上传好。

### 5. 实训任务怎么发布和维护

除了在课程详情里新增任务，你也可以在任务列表中统一查看全部任务。

任务列表中常见操作有：

- 新建任务
- 编辑任务
- 查看详情
- 进入批改
- 删除任务
- 批量删除

任务详情页适合做两件事：

- 核对任务基础信息
- 查看提交人数、批改率、达标率等结果概览

如果发现任务描述不清、截止时间不合适，建议尽早在任务开始阶段完成调整。

### 6. 批改怎么做

批改页面是教师日常最常用的页面之一。

进入后，你可以先在左侧学生列表中筛选：

- 全部
- 待批改
- 已批改

也可以按学生姓名、学号搜索。

选中某个学生后，可以完成这些操作：

- 查看学生提交内容和附件
- 填写分数
- 填写评语
- 提交批改结果
- 打回重做

如果任务量较大，还可以使用以下方式提效：

- 对单个学生使用 AI 初评辅助
- 直接采纳 AI 生成的初评草案后再微调
- 对全部未批改记录发起 AI 批改
- 勾选多名学生后批量打回重做

推荐批改顺序：

1. 先筛选“待批改”。
2. 逐个查看学生提交内容。
3. 给出分数和具体评语。
4. 明显不符合要求的任务直接打回重做。
5. 批改完成后再回看整体进度。

### 7. 教学统计怎么查看

统计页面适合做阶段复盘，帮助教师判断教学效果和学生掌握情况。

你可以按学年、课程、班级、任务逐步筛选，然后查看：

- 总体合格率
- 单个任务通过率
- 最高分、平均分、最低分变化趋势
- 未提交和不及格预警
- 课程下各任务的成绩分析

如果需要名单结果，也可以直接导出学生统计列表。

比较适合使用统计页面的场景：

- 一次任务批改结束后做班级复盘
- 阶段教学结束后看课程整体效果
- 想快速找出高风险任务和需要重点辅导的学生时

### 8. 教师留言怎么处理

教师可以在留言页面按“班级 -> 课程 -> 学生”逐步进入对话。

进入后可以：

- 搜索学生
- 查看历史留言
- 回复学生
- 关闭当前会话
- 重新开启会话

建议把留言页用于这些场景：

- 回答学生对任务要求的疑问
- 解释批改意见
- 跟进被打回重做的学生
- 做简短的一对一辅导

## 三、学生使用手册

### 1. 学生日常操作顺序

建议学生按下面的顺序使用系统：

1. 先看首页提醒，了解待完成任务和新通知。
2. 进入“我的课程”查看当前学习进度。
3. 进入“我的实训任务”完成提交。
4. 批改完成后查看成绩反馈。
5. 定期查看能力分析和实训报告。
6. 在个人信息页维护密码。

### 2. 首页怎么用

学生首页主要是当天学习的总入口。

首页会集中显示：

- 待完成任务数量
- 已完成任务数量
- 平均分
- 未读消息数量
- 近期成绩
- 消息提醒
- 我的课程

推荐习惯：

1. 每次登录先看待完成任务和未读消息。
2. 有新提醒时优先查看，避免错过新任务或打回通知。
3. 从首页直接点进课程，可以更快进入学习状态。

### 3. 我的课程怎么学

“我的课程”页面会按学习方向进行归类，方便你整体查看自己正在学什么、完成到哪一步。

在这里你可以：

- 查看每个方向下有多少门课程
- 查看任务完成进度
- 进入某个方向查看详细课程
- 再进入具体课程详情

课程详情页通常包含三部分：

- 等级闯关
- 课程资源
- 实训任务

建议这样使用：

1. 先看课程资源，了解本次学习需要的资料。
2. 再看实训任务，按要求逐项完成。
3. 通过等级进度判断自己当前完成情况。

### 4. 我的实训任务怎么完成

“我的实训任务”页面适合集中查看所有任务。

你可以按状态筛选：

- 未提交
- 已提交
- 已批改
- 已打回

页面中的常见动作只有两种：

- 还没完成时，点“去提交”
- 已经提交或已批改后，点“查看”

如果你想从课程里进入任务，也可以直接在课程详情页打开对应任务。

### 5. 任务提交怎么做

进入任务提交页后，先看清楚以下内容：

- 截止时间
- 满分值
- 及格线
- 当前状态
- 所属课程
- 任务类型
- 任务等级
- 任务详情

然后按照下面顺序提交：

1. 阅读任务要求。
2. 在提交内容框里写清完成过程、结果和说明。
3. 如任务要求上传附件，再上传对应材料。
4. 检查无误后点击“提交任务”。

如果任务被教师打回，你会看到“重新提交”提示。此时请先根据教师意见修改，再重新提交。

提交时可以注意：

- 文字内容尽量写完整，不要只写一句结果
- 附件名称最好清晰，方便教师识别
- 页面会自动暂存文字内容，避免中途丢失

### 6. 成绩反馈怎么看

任务批改完成后，可以进入反馈页查看结果。

反馈页会展示：

- 我的成绩
- 是否达标
- 及格线
- 所属课程
- 提交时间
- 批改时间
- 教师评语
- 提交附件

建议看反馈时重点关注两件事：

1. 自己是否达标。
2. 教师评语里指出了哪些问题、哪些地方可以继续提升。

如果任务被打回，先根据评语修改，再回到提交页重新提交。

### 7. 能力分析和实训报告怎么看

学生端提供两个层次的结果查看方式。

#### 7.1 能力分析

能力分析页适合快速查看当前整体状态。

你可以看到：

- 综合达标率
- 当前是否达标
- 各项能力达标率
- 优势项
- 薄弱项

如果想看更完整的阶段变化，可以继续进入“完整实训报告”。

#### 7.2 实训报告

实训报告适合做阶段总结。

你可以看到：

- 总任务数
- 已完成数量
- 已达标数量
- 班级排名
- 各项技能分析
- 排名趋势变化

如果你需要留存结果，可以直接导出 PDF。

### 8. 个人信息怎么维护

在个人信息页，你可以查看自己的：

- 姓名
- 学号
- 院系
- 班级
- 手机号
- 邮箱

如果需要修改登录密码：

1. 输入原密码。
2. 输入新密码。
3. 再确认一次新密码。
4. 点击“确认修改”。

建议定期更新密码，避免多人共用设备时产生风险。

## 四、两个角色都适用的小提示

- 先看提醒，再做操作，效率会更高。
- 教师发布任务前，先确认班级和资源是否齐全。
- 学生提交前，先确认任务要求和附件是否完整。
- 被打回并不代表失败，通常表示还需要补充或修正内容。
- 统计页和报告页更适合做阶段复盘，不一定要等到期末再看。

## 五、本文档适用范围

本手册依据当前系统已经实现的页面和业务流程整理，适合作为教师与学生的日常使用说明。
