# V1.0.1.10 追加计划：复制改表单、封存与删除、多班级建错班、预览缩放、负责人列

日期：2026-10-13。并入 V1.0.1.10，与公共课认领一起发布。数据库改动追加到 V21（V21 尚未在任何环境发布）。

## 已确认的决定

- 全部并入 V1.0.1.10。
- 界面上“归档”统一改为“**封存**”。封存 = 只读，**统计照常计入**；删除 = 不计入任何统计。
- 有提交记录的任务**可以删除**，要二次确认。
- 看板上的总数（学生、教师、课程、任务）**只算在用的**；封存针对往期学期，只进入分析类统计。
- 复制任务改为**弹出任务表单**，预先填好原任务内容，老师只需选班级和截止时间。

## 一、多班级建任务建错班（严重）

**根因**：课程详情页“新建任务”弹窗打开时，下拉选项用的是“班课关系 ID”。随后表单的“课程变化”回调异步执行，此时“正在初始化”标志已复位，回调没被跳过，把选项换成了“班级 ID”。提交时又先按“班课关系 ID”查找，两种 ID 撞号时任务建到别的班。打开弹窗时“指定班级”“二级指标”立即标红，也是这个回调造成的。

**改法**：
1. 前端：
   - 课程详情快捷新建（以及下面的“复制”场景）里，跳过课程、一级指标的级联回调；
   - 班级下拉统一只用班课关系 ID，删掉“按班级 ID 兜底”；
   - 补撞号场景的单元测试。
2. 后端兜底：新建接口可选接收 `classCourseId`。传了就校验它与 `courseId`、`classId`、学期一致，不一致拒绝。前端快捷新建和复制都传。
3. 已建错的任务，数据库里分辨不出来，在发布说明里提醒老师自查。

## 二、复制任务：改为弹出表单，直接发布，不再有草稿

**交互**：
- 任务列表和课程详情任务页的行操作“复制”，打开“复制任务”表单，预先填好原任务的全部内容：名称、类型、等级、指标、批改方式、提交方式、分值、及格线、任务内容、AI 评分标准和参考答案。
- 课程默认是原任务的课程。班级为多选，范围是本学期这门课里当前老师能布置的班级；公共课只有自己认领的班级。截止时间要重新选，带快捷按钮。
- 预览、确认后，每个班级生成一个**已发布**的任务，和新建任务一样给学生分配任务、发通知。
- 列表上的“批量复制”去掉：批量复制没法给每个任务改内容，复制改为一次一个任务。

**后端**：
- 新建接口可选接收 `sourceHomeworkId`。校验当前用户能查看来源任务，然后记录来源任务。
- 旧的复制接口（`/copy`、复制目标列表）下线，同步更新接口权限快照。
- 新建、编辑都不再接受草稿状态。

**已有草稿**：
- 列表显示为“待发布”；
- 老师编辑并保存时，后端自动发布：分配学生、发通知，截止时间必填；
- 状态筛选里去掉“草稿”。

## 三、封存与删除

### 实训任务
- **封存**（原“归档”，接口不变）：只读，不能编辑或批改，学生的待办里不再出现；可以恢复。
- **删除**（新增，单个和批量）：
  - 权限：布置者本人或管理员。
  - 有提交记录时二次确认，提示“该任务的提交和成绩将从所有统计中移除，且不能恢复”。
  - 删除方式：逻辑删除任务，并在同一事务里删除它的学生分配、提交记录、AI 批改任务和提醒状态；学生端也不再显示。
  - 权限沿用现有的任务删除权限点，不新增菜单。
- 课程详情任务页补上：
  - “显示已封存”开关；
  - 恢复、删除、复制操作。

### 统计口径
| 统计 | 封存的任务、班级、课程、班课 | 删除的 |
|---|---|---|
| 看板总数（学生、教师、课程、任务） | 不计（只算在用） | 不计 |
| 待办类（待批改、本周提交、最近任务） | 不计 | 不计 |
| 分析类（合格率、成绩趋势、课程分析、学生排名、AI 班级分析） | **计入** | 不计 |
| 学生能力画像、实训报告、往期任务 | 保持现状：提交过的计入 | 不计 |
| 单个任务统计、班课详情的成绩分析 | 计入 | 不计 |
| 学期收尾预览 | 保持现状（只看在用的） | 不计 |

- 班课详情现在会把草稿也算进去，改为排除草稿和已删除的任务。
- 修掉任务列表“只选已封存但没开显示已封存时，结果永远为空”的问题。

### 其他实体
- 班级、课程、班课、学期收尾：界面上的“归档”都改为“封存”，统计口径按上表。
- 这次**不给它们加删除**。
- 题库、课程资源本来就是删除，不改。

### 文字
- 前端所有“归档”改为“封存”，包括按钮、提示、筛选和确认框。
- 后端错误提示同步修改，例如“班课已封存，不能布置任务”。
- 字典标签同步修改：任务状态、班级状态、课程状态里的“已归档”改为“已封存”；任务状态里的“草稿”改为“待发布”。这部分追加到 V21，并同步 check-v21 和基线 21。
- 接口路径和字段名不改。

## 四、课程详情：班级、任务加“负责人”列和筛选

- **班级页“负责人”**：
  - 公共课：认领人，没人认领显示“未认领”；
  - 专属课：添加这个班的教师。系统或管理员添加的，显示课程负责人。
- **任务页“负责人”**：任务布置者。
- **筛选**：两页都加“负责人”下拉，选项是列表里出现的人；公共课的班级页另有“未认领”选项。这两个列表本来就是一次性全部加载，在前端筛选即可。
- 后端在课程详情返回里补字段：
  - 班级行：`ownerId`、`ownerName`；
  - 任务行：`teacherId`、`teacherName`、`status`（用来显示已封存和待发布）。
  - 任务行改为包含封存的任务，由前端开关控制显示。

## 七、风险

- 删除不可恢复：靠二次确认，并且只有布置者或管理员能删。
- 统计口径变化后，老师看到的往期合格率等数字会变（封存的数据回来了），要写进发布说明。
- 旧复制接口下线：只有前端在用，前端会同步改；在发布说明里注明。
