# 构建说明

生产构建请始终在仓库根目录执行：

```bash
pnpm run build:production
```

该入口会先构建 `web-antd` 依赖的工作区包，再构建应用。不要直接执行 `pnpm -F @vben/web-antd run build`；安装后生成的 workspace stub 只供开发解析，不能作为生产依赖产物。

本地开发使用 `pnpm run dev:antd`。

Docker 镜像构建使用 `pnpm run build:docker`，默认标签为 `nus-front:local`。发布时显式指定标签，例如：

```bash
FRONTEND_IMAGE=nus-front:release-YYYYMMDD.N pnpm run build:docker
```

脚本只构建镜像，不操作已有容器。依赖安装和生产构建由 Dockerfile 完成；跨平台离线发布还需按主仓库部署说明准备 `linux/amd64` 镜像。
