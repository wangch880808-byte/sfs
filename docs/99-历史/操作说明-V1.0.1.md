# 师砺平台离线部署简明手册

适用于刚装好系统的学校服务器，离线安装包已复制到服务器。本手册以 V1.0.1 为例。

## 1. 登录服务器

登录学校堡垒机，在服务器列表中找到指定的服务器，打开 SSH 终端。以下命令都在这台服务器的终端中执行。

开始前确认：**目标服务器、安装包所在目录、平台访问 IP，以及可使用 sudo 的账号**。不要把命令执行在堡垒机自身的终端中。

## 2. 确认系统

依次执行：

```bash
cat /etc/os-release
uname -m
```

系统应为 **Ubuntu 24.04**，架构应为 **x86_64**。不一致时先停止操作并联系运维负责人。

## 3. 进入安装包目录

将下面的 `/实际安装包所在目录` 替换为安装包实际存放的目录：

```bash
cd /实际安装包所在目录
ls
```

如果看到的是压缩包 `nus-offline-V1.0.1-ubuntu24.04-amd64.tar.gz`，执行：

```bash
tar -xzf nus-offline-V1.0.1-ubuntu24.04-amd64.tar.gz
cd nus-offline-V1.0.1-ubuntu24.04-amd64
```

如果已经解压，直接进入 `nus-offline-V1.0.1-ubuntu24.04-amd64` 文件夹，不用再次解压。如果当前路径就是这个文件夹，直接继续下一步。

校验安装文件：

```bash
sha256sum --check SHA256SUMS
```

全部显示 `OK` 或“成功”后继续。如有 `FAILED`、文件缺失或其他错误，停止操作并将报错反馈给运维负责人。

## 4. 开始安装

把下面的 `服务器IP` 替换为实际的平台访问 IP，不要填写堡垒机 IP：

```bash
sudo NUS_SITE_URL=http://服务器IP ./install.sh
```

- 如果提示 `[sudo] password`，输入当前服务器登录账号的密码。
- 出现 `New admin password` 时，设置平台管理员密码；出现 `Confirm admin password` 时，再输入一次。
- 管理员密码要求：**12～16 位，包含大写字母、小写字母、数字和特殊字符，不使用中文**。
- 输入密码时屏幕不显示字符，这是正常现象。

安装需要一段时间，请保持堡垒机连接，不要关闭终端。看到 **`Installation completed`** 表示安装脚本完成。

安装会自动配置 Docker 和平台服务，不需要另外安装 Java、Node.js 或下载镜像。

## 5. 检查并登录

依次执行：

```bash
sudo nusctl status
sudo nusctl doctor
curl --fail http://127.0.0.1/nginx-health
```

确认服务正常运行，没有 `unhealthy`、`Exited` 或明显报错。然后在能访问学校服务器的电脑浏览器中打开：

```text
http://服务器IP/
```

登录账号：`admin`；登录密码：安装时设置的管理员密码。

如果服务器检查正常，但电脑无法打开网页，请联系运维负责人确认校园网络或堡垒机的访问方式，不要自行修改防火墙。

## 6. 完成后反馈

记录**平台访问地址、服务状态截图、登录成功截图**并完成交接。管理员密码通过约定的私密方式交接，不放进截图或群聊。

如果中途报错，保留终端最后的报错内容并联系运维负责人。不要自行删除 `/srv/nus`、重置数据库或反复重装。

> 离线安装不需要互联网。外部 AI 和校园资讯抓取需要额外的网络与配置，由运维负责人后续配置。
