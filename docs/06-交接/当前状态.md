## 已知问题与待办

可以作为新同学的第一批任务。认领前先在 Gitee 的 Issue 里登记。

| 优先级 | 问题 | 说明 |
| --- | --- | --- |
| **高** | `nusctl backup` 只备份数据库，不备份上传附件（`/srv/nus/data/uploads`）和 `/srv/nus/config/.env` | `.env` 里有解密数据库中 AI 平台 key 所需的密钥，服务器损坏时只有数据库备份不够。运维手册已写手动备份方法，应做进 `nusctl backup` |
| **高** | 没有定时备份和失败告警 | 运维手册给了 crontab 脚本示例，需要在学校服务器上配置并演练 |
| 中 | 没有重置管理员口令、更换数据库或 Redis 口令的命令 | 运维手册写了手动方法，需在测试服务器演练；改口令后，旧的 `.env` 副本仍是旧口令，回滚到旧版本会连不上数据库 |
| 中 | `build-release.sh`（全量安装包）不检查工作区是否干净，不写 BUILD-METADATA，不生成压缩包 | 与 `build-update.sh` 的做法对齐 |
| 低 | `configure-domain.sh` 不在升级包里，要从仓库单独拷到服务器 | 见运维手册“域名与 HTTPS” |
