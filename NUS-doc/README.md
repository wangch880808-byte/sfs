## 数据库基线的规则

- **全新安装**：导入基线，再执行比基线版本新的迁移（`deploy/database/migrations/V*.sql`）。
- **已安装的服务器升级**：只执行新增的迁移，不会再导入基线。
- **新增迁移 V<N> 时，基线必须同步更新到 N**：
  - 保证“基线 N”和“基线 N-1 加上 V<N>”的结果完全一致；
  - 文件头改为 `-- Flyway baseline version: N`；
  - 由 `deploy/database/tests/check-v<N>.py` 验证。
- **默认管理员口令**：基线里只有一个管理员账号 `admin`，口令是脚手架默认值。首次部署必须用 bootstrap 改掉，见运维手册。
- **不要把真实数据导出到这里**：生产库备份、含真实姓名或手机号的 SQL 一律不入库。本目录的 `.gitignore` 已拦截基线以外的 SQL。

详细做法见 [`docs/03-开发/数据库迁移.md`](../docs/03-开发/数据库迁移.md)。
